# Particle Hero — شخصیت مکعبی از جنس نور

یک تجربه‌ی هیرو تعاملی و پریمیوم برای وردپرس و المنتور: یک شخصیت مکعبی آینده‌نگر که
کاملاً از ذرات نورانی ساخته شده، مستقیماً روی GPU اجرا می‌شود و هیچ مدل سه‌بعدی‌ای
دانلود نمی‌کند.

| حالت | چه اتفاقی می‌افتد |
| --- | --- |
| لود صفحه | ذرات در یک ابر غبار شناورند و طی حدود **۵ ثانیه** روی مسیرهای منحنی به مرکز جمع می‌شوند و شخصیت را می‌سازند |
| بعد از شکل‌گیری | هسته‌ی نارنجی سینه روشن می‌شود، نبض می‌گیرد و نورش را روی ذرات آبی اطراف پخش می‌کند |
| موس | شخصیت به سمت نشانگر متمایل می‌شود و ذرات دور آن رانده و چرخانده می‌شوند |
| اسکرول | شخصیت به‌نرمی به ذرات متلاشی می‌شود و با برگشت به بالا دوباره ساخته می‌شود |

---

## چرا این‌طور ساخته شده

**همه‌چیز روی GPU.** هیچ بافر ورتکسی بعد از آپلود اولیه دست‌کاری نمی‌شود. تمام
حالت‌های ذره — شکل‌گیری، انحلال، واکنش به موس، جریان نویز — در شیدر از روی چند
یونیفرم اسکالر محاسبه می‌شوند. به همین دلیل ۹۶ هزار ذره‌ی افزایشی روی دسکتاپ و
۲۲ هزار ذره روی موبایل با ۶۰ فریم اجرا می‌شود.

**شخصیت داده است، نه فایل.** بدنه در `src/character/CharacterBlueprint.js` به شکل
فهرستی از جعبه‌های محوری تعریف شده و در زمان اجرا با نمونه‌برداری وزن‌دار بر اساس
مساحت سطح به ذره تبدیل می‌شود. چیزی برای fetch کردن یا decode کردن وجود ندارد و
سیلوئت با تغییر چند عدد قابل بازطراحی است.

**بلوم اختصاصی.** به‌جای `EffectComposer` سه‌جی‌اس، یک خط لوله‌ی پنج‌درا نوشته شده
که دقیقاً همان چیزی را انجام می‌دهد که لازم است: bright pass، دو اکتاو بلور جداپذیر،
و یک پاس ترکیب که تن‌مپینگ ACES، وینیت و گرین را هم در همان شیدر انجام می‌دهد.

## نصب روی وردپرس

۱. پوشه‌ی `wordpress-plugin/particle-hero` را در `wp-content/plugins/` کپی کنید
   (یا از آن یک فایل zip بسازید و از مسیر *افزونه‌ها ← افزودن ← بارگذاری* نصب کنید).
۲. افزونه را فعال کنید.
۳. در المنتور ویجت **Particle Hero** را داخل یک سکشن بکشید — یا از شورت‌کد استفاده کنید.

افزونه به المنتور وابسته نیست؛ بدون آن هم شورت‌کد و تابع قالب کار می‌کنند.

### شورت‌کد

```
[particle_hero
  height="100vh"
  title="آینده، ذره به ذره ساخته می‌شود"
  subtitle="یک تجربه‌ی سه‌بعدی تعاملی، مستقیماً روی GPU"
  button_text="شروع کنید"
  button_url="/contact"
  color_core="#ff7a1a"]
```

### داخل قالب

```php
<?php
particle_hero_render( array(
    'height'             => '100vh',
    'title'              => 'آینده، ذره به ذره',
    'formation_duration' => 5.2,
    'quality'            => 'auto',
) );
```

### کنترل‌های المنتور

| بخش | چه چیزی را تنظیم می‌کند |
| --- | --- |
| Content | متن، دکمه، ترازبندی، ارتفاع ریسپانسیو |
| Character | اندازه، فاصله‌ی دوربین، آفست عمودی، اندازه‌ی ذره، seed |
| Formation | مدت شکل‌گیری، تأخیر، پخش‌شدگی (stagger)، انحنای مسیر |
| Motion & interaction | drift سطح بدن، چرخش آرام، sway، واکنش موس، انحلال با اسکرول |
| Palette | هر هشت رنگ: سایه، آبی اصلی، های‌لایت لبه، هسته، پوسته‌ی هسته، و پس‌زمینه |
| Effects | بلوم، اکسپوژر، وینیت |
| Performance | پریست کیفیت، override تعداد ذره، لود تنبل، توقف در خارج از دید، تصویر fallback |

## توسعه

```bash
npm install
npm run dev     # پلی‌گراند روی http://localhost:5173 همراه پنل تنظیم زنده
npm run build   # باندل را مستقیماً داخل assets افزونه می‌نویسد
```

`npm run build` هر دو خروجی را می‌سازد:

- `wordpress-plugin/particle-hero/assets/js/particle-hero.min.js` — باندل IIFE که
  `window.ParticleHero` را می‌سازد (همانی که افزونه enqueue می‌کند)
- `wordpress-plugin/particle-hero/assets/js/particle-hero.esm.js` — نسخه‌ی ESM
  برای پروژه‌های غیر وردپرسی

برای بررسی خروجی نهایی بدون نصب وردپرس، `demo/wordpress-preview.html` را باز کنید:
این فایل دقیقاً همان مارک‌آپی را دارد که `Particle_Hero_Renderer::render()` تولید می‌کند.

## API جاوااسکریپت

```js
const hero = ParticleHero.mount('#hero', {
  quality: 'high',
  formation: { duration: 5.2, stagger: 0.55 },
  colors: { core: '#ff7a1a', mid: '#2f7dff' },
});

hero.replay();                 // پخش دوباره‌ی شکل‌گیری
hero.setDissolve(0.6);         // کنترل دستی انحلال
hero.setColors({ core: '#00e5ff' });
hero.pause();  hero.play();
hero.refresh();                // بعد از تغییر چیدمان (تب، آکاردئون المنتور)
hero.destroy();
```

رویدادها هم روی خود المنت منتشر می‌شوند:

```js
el.addEventListener('particlehero:formed', () => { /* شخصیت کامل شد */ });
el.addEventListener('particlehero:core-online', () => { /* هسته روشن شد */ });
```

## پرفورمنس

| tier | ذرات | حداکثر pixel ratio | مقیاس بلوم |
| --- | --- | --- | --- |
| high | ۹۶٬۰۰۰ | ۲٫۰ | ۰٫۵ |
| medium | ۵۲٬۰۰۰ | ۱٫۷۵ | ۰٫۳۵ |
| low | ۲۲٬۰۰۰ | ۱٫۳۵ | ۰٫۲۵ |

انتخاب tier از روی تعداد هسته‌های CPU، حافظه، پشتیبانی WebGL2، نوع نشانگر و
تعداد واقعی پیکسل‌های صفحه (با احتساب مجذور DPR) انجام می‌شود.

علاوه بر آن:

- اگر فریم‌ریت زیر هدف بماند، کیفیت پله‌پله کم می‌شود: اول pixel ratio، بعد
  رزولوشن بلوم، و در آخر خود بلوم. هیچ‌وقت دوباره بالا نمی‌رود، چون نوسان کیفیت
  از یک تصویر کمی نرم‌تر آزاردهنده‌تر است.
- وقتی هیرو از دید خارج می‌شود یا تب مخفی است، حلقه‌ی رندر **کاملاً متوقف** می‌شود.
- هیروی پایین صفحه به‌صورت تنبل و فقط با نزدیک‌شدن به viewport مانت می‌شود.
- باندل با `defer` و فقط در صفحاتی که واقعاً هیرو دارند enqueue می‌شود.

## دسترس‌پذیری و سازگاری

- `prefers-reduced-motion: reduce` → شخصیت در یک فریم ثابت و کاملاً ساخته‌شده رندر
  می‌شود؛ نه شکل‌گیری، نه انحلال، نه حلقه‌ی رندر.
- بدون WebGL → کلاس `particle-hero--unsupported` روی کانتینر می‌نشیند و تصویر
  fallback نمایش داده می‌شود.
- بوم `aria-hidden` است و متن روی آن HTML واقعی و قابل انتخاب باقی می‌ماند.
- WebGL2 ترجیح داده می‌شود ولی روی WebGL1 هم اجرا می‌شود (بلوم به LDR برمی‌گردد).
