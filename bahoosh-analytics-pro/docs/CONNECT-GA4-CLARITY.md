# اتصال گوگل آنالیتیکس ۴ و مایکروسافت کلاریتی به باهوش

این دو سرویس روی سایت شما نصب هستند و دارند داده جمع می‌کنند. کاری که اینجا انجام می‌دهیم
این است که به افزونه اجازه **خواندن** آن داده‌ها را بدهیم تا در همان تحلیلی که از ووکامرس
می‌سازد استفاده شوند.

نصب بودن اسکریپت روی سایت کافی نیست. اسکریپت داده را به گوگل و مایکروسافت **می‌فرستد**؛
برای **پس گرفتن** آن داده به یک کلید دسترسی جداگانه نیاز است. هر دو رایگان‌اند.

---

## چرا این اتصال ارزش دارد

| منبع | چه چیزی اضافه می‌کند | چه چیزی اضافه نمی‌کند |
|---|---|---|
| ووکامرس (پیش‌فرض) | سفارش‌ها، محصولات، سبد خرید، درآمد به تفکیک دستگاه | رفتار کاربری که به سفارش نرسیده |
| رهگیری داخلی افزونه | قیف خرید، صفحات خروج | فقط از لحظه نصب این نسخه به بعد |
| **گوگل آنالیتیکس ۴** | **تاریخچه پیش از نصب افزونه**، نرخ تبدیل هر دستگاه | جزئیات فنی خرابی صفحه |
| **مایکروسافت کلاریتی** | **دلیل رها کردن خرید**: کلیک عصبی، کلیک بی‌اثر، خطای جاوااسکریپت روی هر صفحه | داده فروش |

نکته مهم: هیچ‌کدام جای داده خود افزونه را نمی‌گیرند. اضافه می‌شوند، جایگزین نمی‌شوند. هر Fact
با برچسب `source` مشخص می‌کند از کدام سیستم آمده، پس همیشه می‌شود فهمید یک عدد را چه کسی گفته.

---

## بخش ۱ — گوگل آنالیتیکس ۴

گوگل برای خواندن داده، اجازه را به یک «سرویس‌اکانت» می‌دهد؛ یعنی یک حساب رباتی که فقط
همین یک کار را می‌کند. این امن‌تر از دادن رمز حساب گوگل خودتان است و هر لحظه قابل لغو است.

### گام ۱ — شناسه Property را پیدا کنید

۱. وارد [analytics.google.com](https://analytics.google.com) شوید.
۲. پایین سمت چپ روی **Admin** (چرخ‌دنده) بزنید.
۳. در ستون Property روی **Property Settings** بزنید.
۴. بالا سمت راست عددی می‌بینید به نام **PROPERTY ID**، چیزی شبیه `483920174`.

> این با کد `G-XXXXXXXXXX` فرق دارد. آن کد برای **فرستادن** داده است؛ این عدد برای **خواندن**.
> اگر کد `G-` را وارد کنید، اتصال کار نمی‌کند.

### گام ۲ — سرویس‌اکانت بسازید

۱. به [console.cloud.google.com](https://console.cloud.google.com) بروید (با همان حساب گوگلی که
   به آنالیتیکس دسترسی دارد).
۲. اگر پروژه‌ای ندارید، بالا سمت چپ یک پروژه جدید بسازید؛ نامش مهم نیست.
۳. از منو: **APIs & Services ← Library**، عبارت `Google Analytics Data API` را جست‌وجو کنید و
   روی **Enable** بزنید. (این گام را رد نکنید؛ بدون آن گوگل خطای دسترسی می‌دهد.)
۴. از منو: **APIs & Services ← Credentials ← Create Credentials ← Service account**.
۵. یک نام بگذارید، مثلاً `bahoosh-reader`. نقش (Role) لازم نیست؛ **Done** را بزنید.
۶. روی سرویس‌اکانتی که ساختید کلیک کنید ← تب **KEYS** ← **Add key ← Create new key ← JSON**.
۷. یک فایل `.json` دانلود می‌شود. **این فایل کلید ورود است؛ مثل رمز عبور با آن رفتار کنید.**

### گام ۳ — به سرویس‌اکانت اجازه خواندن بدهید

فایل JSON را که باز کنید، خطی شبیه این دارد:

```json
"client_email": "bahoosh-reader@your-project.iam.gserviceaccount.com"
```

۱. این ایمیل را کپی کنید.
۲. به گوگل آنالیتیکس برگردید: **Admin ← Property Access Management**.
۳. بالا سمت راست **+** ← **Add users**.
۴. ایمیل را بچسبانید، نقش **Viewer** را بدهید و **Add** بزنید.

> بیشترین خطایی که در این مرحله رخ می‌دهد همین است: سرویس‌اکانت ساخته شده ولی به Property
> اضافه نشده. اگر افزونه پیام «گوگل دسترسی را رد کرد» داد، همین گام را دوباره بررسی کنید.

### گام ۴ — در وردپرس وارد کنید

۱. **باهوش ← تنظیمات ← منابع داده بیرونی**.
۲. عدد Property ID را در «شناسه Property گوگل آنالیتیکس ۴» بگذارید.
۳. **کل محتوای فایل JSON** را (از `{` تا `}`) در کادر «فایل سرویس‌اکانت گوگل» بچسبانید.
۴. ذخیره کنید.

پس از ذخیره، فقط ایمیل سرویس‌اکانت به‌صورت ماسک‌شده نمایش داده می‌شود. کلید خصوصی هرگز به
مرورگر برنمی‌گردد، در گزارش عیب‌یابی نمی‌آید و در هیچ لاگی نوشته نمی‌شود.

---

## بخش ۲ — مایکروسافت کلاریتی

خیلی ساده‌تر است: کلاریتی یک توکن می‌دهد و تمام.

۱. وارد [clarity.microsoft.com](https://clarity.microsoft.com) شوید و پروژه سایت خود را باز کنید.
۲. **Settings ← Data Export** (در بعضی نسخه‌ها زیر عنوان *API*).
۳. روی **Generate new API token** بزنید، یک نام بگذارید و توکن را کپی کنید.
   توکن فقط همان یک بار کامل نمایش داده می‌شود.
۴. در وردپرس: **باهوش ← تنظیمات ← منابع داده بیرونی ← توکن مایکروسافت کلاریتی**، بچسبانید و ذخیره کنید.

### دو محدودیت که باید بدانید

کلاریتی این دو محدودیت را خودش گذاشته و افزونه نمی‌تواند دورشان بزند؛ فقط با آن‌ها صادق است:

- **روزی ۱۰ درخواست** برای هر پروژه. به همین دلیل نتیجه شش ساعت کش می‌شود و تعداد
  درخواست‌های امروز زیر همان فیلد نمایش داده می‌شود.
- **حداکثر ۳ روز اخیر.** اگر بازه تحلیل شما ۳۰ روز باشد، داده کلاریتی همچنان ۳ روزه است.
  افزونه این را به‌عنوان یک هشدار در بسته تحلیل می‌نویسد تا مدل عدد سه‌روزه را به‌جای
  عدد ماهانه تفسیر نکند.

## بعد از اتصال چه اتفاقی می‌افتد

به **باهوش ← مرکز هوش مصنوعی** بروید و «اجرای تحلیل» را بزنید. در پنل «منابع داده» سمت چپ
باید هر دو سرویس «متصل» نشان داده شوند، و در بخش «اعدادی که مدل دید» Factهایی با شناسه
`fact_ga4_…` و `fact_clarity_…` ظاهر می‌شوند.

نمونه چیزی که کلاریتی اضافه می‌کند:

```
[critical · ۷۸٪] خطای اسکریپت در صفحه /checkout
کلاریتی در ۳۱۲ نشست (۱۸.۴ درصد نشست‌های این صفحه) طی ۳ روز گذشته این نشانه را ثبت
کرده است. کنسول مرورگر را روی همین صفحه باز کنید؛ این معمولاً ریشه اصلی رها کردن خرید است.
```

این دقیقاً همان چیزی است که با داده ووکامرس به‌تنهایی نمی‌شد فهمید: ووکامرس می‌گوید سفارش
ثبت نشده، کلاریتی می‌گوید چرا.

## اگر کار نکرد

| پیام | معنی | راه‌حل |
|---|---|---|
| «گوگل دسترسی را رد کرد» | سرویس‌اکانت به Property اضافه نشده | گام ۳ بخش ۱ |
| «شناسه Property تنظیم نشده» | فیلد خالی است یا کد `G-` وارد شده | عدد خالص را بگذارید |
| «کلید خصوصی قابل خواندن نبود» | JSON ناقص کپی شده | کل فایل، از `{` تا `}` |
| «افزونه OpenSSL فعال نیست» | PHP سرور بدون OpenSSL کامپایل شده | از هاست بخواهید فعالش کند |
| «توکن کلاریتی پذیرفته نشد» | توکن منقضی یا اشتباه است | توکن تازه بسازید |
| «سهمیه روزانه کلاریتی تمام شده» | امروز ۱۰ بار درخواست رفته | فردا، یا از نتیجه کش‌شده استفاده کنید |

## اگر اصلاً وصل نکنید

افزونه بدون این دو هم کار می‌کند. تحلیل محصول، پکیج، دستگاه و درآمد کاملاً از ووکامرس
می‌آید و به هیچ سرویس بیرونی وابسته نیست. تنها چیزی که از دست می‌دهید تاریخچه پیش از نصب
(گوگل) و تشخیص خرابی فنی صفحه (کلاریتی) است.
