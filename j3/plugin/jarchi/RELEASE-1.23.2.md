# Jarchi 1.23.2

## Ticket admin reply flow
- Support replies now return to the same ticket inside WordPress admin instead of the public customer ticket centre.
- The refreshed admin ticket immediately shows the new `answered` status and reply thread.

## Open-ticket navigation count
- The support sidebar's `تیکت‌ها` group shows the number of open tickets.
- `open = all tickets - closed tickets`.
- The UI is intentionally only a black number with no badge background or border.
