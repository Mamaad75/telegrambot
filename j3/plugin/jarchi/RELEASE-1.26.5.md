# Release 1.26.5

This release adds a safe, copy-only editor for automatic-ticket templates. Administrators select the WordPress roles that may edit template copy. Authorized non-admin users receive a small **قالب‌های جارچی** admin screen and can change only the ticket subject and body of preset-derived rules that have already been added.

Automation mechanics remain protected: triggers, conditions, status, departments, categories, delays, reply policy, deletion and custom hooks cannot be changed from the designer editor.
