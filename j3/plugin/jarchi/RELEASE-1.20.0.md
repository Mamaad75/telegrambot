# Jarchi WordPress Plugin 1.20.0

این انتشار روی دو محور اصلی است: **کشف و انتشار مطمئن فیلدهای داینامیک** و **بازطراحی کامل تجربه تیکت**.

### مهم‌ترین تغییرات
- Field Mapping روی مسیر مرکزی پنل جارچی به‌درستی JS خود را بارگذاری می‌کند.
- کشف runtime برای metaهای نوشته و fallback کامل‌تر JetEngine اضافه شده است.
- مرکز کاربری جارچی دیگر خودکار ساخته نمی‌شود و کاملاً opt-in است.
- لیست تیکت کاربر و ثبت تیکت از هم جدا شده‌اند؛ FAQ قبل از فرم قرار گرفته است.
- لیست مدیریت تیکت به جدول ریسپانسیو تبدیل شده است.
- پاسخ آمادهٔ فارسی و Badge واقعی اصلاح شده‌اند.

### سازگاری
- WordPress 6.5+
- PHP 8.1+
- بدون migration دیتابیس اجباری؛ تنظیمات و تیکت‌های موجود حفظ می‌شوند.
