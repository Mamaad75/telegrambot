# Jarchi 1.14.0

## Product model

The WordPress Ticket Center is a standalone site feature. It works entirely without the Jarchi Mini App or backend.

The Jarchi Mini App is a separate, optional control plane for Jarchi clients (site administrators). Remote site-changing actions are granted only when the client has an active paid Jarchi Mini App plan. Trial subscriptions do not grant remote control.

## Ticket operations
- SLA first-response and resolution targets
- Escalation email alerts
- Agent performance metrics
- Existing tickets, departments, categories, canned replies, ratings, SMS and Elementor remain intact
